# A52s 5G Turbo Launcher (Samsung Galaxy A52s - SM-A528B)

## Cara Build APK Otomatis Tanpa PC (Lewat GitHub Actions di Browser HP)
1. Ekstrak `A52sTurboLauncher-v2.zip`.
2. Buat repository baru (gratis) di [github.com](https://github.com) lewat browser Samsung Galaxy A52s Anda.
3. Unggah seluruh isi folder `A52sTurboLauncher-v2` (termasuk folder tersembunyi `.github/workflows/build-apk.yml`) ke repository tersebut.
4. Buka tab **Actions** pada repository Anda — GitHub akan otomatis mengompilasi proyek dan menandatangani file APK (`app-debug.apk`) dalam ~2 menit.
5. Unduh artifact **`A52sTurboLauncher-debug-apk`**, ekstrak, lalu instal **`app-debug.apk`** langsung di Galaxy A52s 5G Anda.
